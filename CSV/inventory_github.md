## Mini_NPU

- 공개여부: public
- URL: https://github.com/hyun02063185-AX-beginner/Mini_NPU

> # Mini NPU Simulator

> MAC(Multiply-Accumulate) 연산으로 패턴이 십자가(Cross)인지 X인지 판별하는 Python 콘솔 앱입니다. 사용자가 직접 3×3 필터/패턴을 입력하거나, `data.json`에 저장된 5×5·13×13·25×25 데이터를 일괄 분석할 수 있습니다.

> - Python 3.12.13 (`python --version`으로 확인)
> - 외부 라이브러리 없음 — 표준 라이브러리 `json`, `time`만 사용

> # AX Work Clinic 방문자 분석 경험 v1

> AX Work Clinic의 방문자 분석 경험 v1 코드베이스입니다. 방문자가 바꾸고 싶은 업무 장면을 한 문장으로 입력하면, 로컬 fallback 규칙과 케이스·근거 라이브러리를 통해 현재 필요한 단계와 오늘 끊을 지점을 안내합니다.

> - Public 방문자 흐름: `/`, `/public`, `/public/analysis`, `/public/diagnosis`, `/public/result`
> - 방문자 분석 엔진: `services/visitor-analysis`
> - 파일 기반 케이스 라이브러리: `data/analysis-cases/cases.json`
> - 파일 기반 근거 라이브러리: `data/analysis-evidence/evidence.json`
> - 내부 운영 콘솔: `/ops/analysis`
> - 운영 검토 상태와 메모: `services/ops-review`
> - 입력 품질 신호 로그: `services/public-events`
