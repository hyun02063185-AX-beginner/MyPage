# Harbor Fleet Presence — Human Review Direction
## Portfolio World — Retro Harbor Campus

Status: `RECORDED_IN_FLEET_PRESENCE_CLOSEOUT`

## Fleet presence

- Sailing vessels had felt too small.
- Ships are a harbor attraction and visual focal point; exact building-scale matching is not required.
- Enlargement up to roughly 1.5× was acceptable.
- The accepted refinement uses differentiated enlargement rather than a uniform 1.5× treatment:
  - Hero: 1.35×
  - Medium: 1.30×
  - Brig: 1.25×
  - Cutter: 1.30×

## Vessel orientation

- The fleet must not all face the same direction.
- Mixed left/right orientation is preferred.
- Vessel material overlap is not acceptable.

## Harbor zoning

Waterfront / dock zone prioritizes vessels, ropes, nets, loading and work props, and maritime working assets.

Harbor Square / civic zone prioritizes trees, shrubs, benches, planters, and park-like resting elements.

## Design principle

> 항구는 완벽하게 정돈된 공간보다 기능적으로 약간 흐트러진 작업 공간처럼 보이는 편이 자연스럽다.

`PURPOSEFUL_IRREGULARITY = REQUIRED`

`MATERIAL_VISUAL_COLLISION = NOT_ACCEPTABLE`

The following remain locked visual rules: moored sailing ships use furled sails; the Hero reads as an Age-of-Sail focal vessel; fleet direction is mixed; class hierarchy remains legible; and waterfront work / civic-square zoning stays distinct.
