# Retro Harbor Campus — Art Direction v1.0

> Recommended repo path: `reports/portfolio-world/art-direction/retro-harbor-campus-art-direction-v1.0.md`

## 1. Document Purpose

이 문서는 Portfolio World의 최종 비주얼 방향을 정의한다.

기능 구현과 공간 구조는 기존 Sprint 1~2의 결정을 유지하고,
이 문서에서는 그 위에 적용할 Art / World Design 기준을 확정한다.

이후 Codex, Claude Code, 기타 구현 Agent는
이 문서를 Portfolio World의 시각적 기준으로 사용한다.

---

## 2. Theme

### Theme Name

**Retro Harbor Campus**

### Core Concept

1990년대 16-bit RPG와 항구도시의 탐험 감성을 바탕으로,
AI 강사 포트폴리오의 Career / Teaching / Making / Gallery를
걸어다니며 발견하는 공간으로 재해석한다.

핵심 조합:

```text
Retro Harbor Atmosphere
+
Portfolio Museum Structure
+
Walkable RPG-like Exploration
```

특정 게임의 맵이나 그래픽을 복제하지 않는다.

고전 RPG와 항구도시에서 다음의 디자인 문법만 차용한다.

- 탐험 가능한 작은 마을
- 명확한 랜드마크
- 건물 중심의 목적지
- 생활감을 주는 환경 오브젝트
- 항구의 수변 / 부두 / 선박 요소
- 직관적인 길찾기

---

## 3. Selected Visual Direction

비교 시안 중 **1번 시안**을 기본 Visual Direction으로 채택한다.

### Base

**Refined Retro Harbor**

특징:

- 밝고 정돈된 항구
- 석재와 목재 중심
- 청록/푸른 바다
- 전문적인 포트폴리오 공간과 어울리는 절제감
- 게임 세계이지만 지나치게 장난감처럼 보이지 않음

### Secondary Reference

3번 시안의 다음 요소를 일부 차용한다.

- 풍부한 환경 오브젝트
- 생활감
- 식재
- 시장 / 항구 소품
- 작은 디테일

### Structural Reference

2번 시안에서는 다음만 참고한다.

- 명확한 건물 실루엣
- 게임 맵으로서의 가독성
- 목적지 간 시각적 구분

---

## 4. Visual Design Principle

가장 중요한 디자인 원칙:

> **World는 Retro Game Inspired, UI는 Modern Portfolio**

즉:

```text
World
= 16-bit inspired harbor world

Portfolio UI
= modern / clean / professional
```

월드의 시각적 재미 때문에 실제 포트폴리오 정보 전달력이 떨어져서는 안 된다.

---

## 5. Mood

전체 분위기는 다음을 지향한다.

```text
Bright
Warm
Open
Explorable
Professional
Creative
Welcoming
```

다음 방향은 피한다.

```text
Dark Pirate Port
Heavy Medieval Fantasy
Horror Harbor
Overly Cute Chibi World
```

항구는 모험의 출발점처럼 보여야 하지만
음침한 해적 항구처럼 보여서는 안 된다.

## 6. Core Material Language

World의 핵심 물성은 네 가지다.

```text
Water
Wood
Stone
Greenery
```

### Water

항구라는 정체성을 만드는 핵심 요소.

사용 위치:

- 남쪽 waterfront
- dock
- canal / small water edge
- boat surroundings

### Wood

항구의 생활감과 작업 공간 표현.

사용 위치:

- dock
- workshop
- crates
- barrels
- stalls
- fences
- signs

### Stone

Portfolio 공간의 안정감과 전문성을 담당.

사용 위치:

- plaza
- destination buildings
- stairs
- retaining walls
- forecourts

### Greenery

World가 지나치게 건조하거나 산업적으로 보이지 않게 한다.

사용 위치:

- planters
- flowers
- trees
- waterfront vegetation
- destination entrance areas

## 9. Harbor Square

### Role

Portfolio World의 중심 Hub.

사용자는 이 공간에서 다음을 즉시 이해해야 한다.

- 네 방향에 주요 목적지가 존재한다.
- 이곳은 항구도시다.
- 자유롭게 걸어다닐 수 있다.
- 포트폴리오의 출발점이다.

### Visual Components

- 중앙 Landmark
- stone plaza
- directional paths
- sign system
- benches
- lamps
- planters
- small harbor props
- market hint
- waterfront hint

### Central Landmark

후보:

- armillary sphere
- compass sculpture
- navigation globe
- stylized harbor map monument

항해 / 탐색 / 학습의 의미를 동시에 담을 수 있어야 한다.

## 15. Asset Vocabulary

최종 World는 현재 Sprint 2 테스트보다
훨씬 높은 환경 밀도를 가진다.

단, 모든 asset이 gameplay object일 필요는 없다.

### Primary

World를 정의하는 대형 요소.

Target:

```text
6–10
```

Examples:

- four destination buildings
- dock
- boat
- lighthouse / harbor tower
- major plaza landmark
- warehouse structure

### Secondary

Zone의 역할과 분위기를 만드는 요소.

Target:

```text
15–25
```

Examples:

- stalls
- anchors
- large crate stacks
- barrels
- signs
- benches
- large planters
- maps
- lamps
- small structures

### Detail

생활감을 만드는 작은 요소.

Target:

```text
30–50
```

Examples:

- ropes
- small crates
- sacks
- small barrels
- flags
- plants
- cargo
- fishing props
- small signs
- flowers

전체적으로 최종 World에는 수십 개의 환경 요소가 존재할 수 있다.

---

## 16. Density Policy

Zone별 밀도를 다르게 한다.

### High / Medium-High

```text
Harbor Square
Destination Forecourts
Waterfront
Market Area
```

### Medium

```text
Primary Paths
Landmark Nodes
Building Surroundings
```

### Low / Medium-Low

```text
Outer Buffer
Peripheral Scenery
```

중요 원칙:

```text
Visual Density != Collision Density
```

보기에는 풍성해야 하지만 이동은 편안해야 한다.

---

## 17. Collision Policy

기존 Sprint 2 collision 정책을 유지한다.

### Collidable

주로 다음만 collision 후보가 된다.

- buildings
- large planters
- water boundaries
- large structures
- selected large props

### Usually Non-Collidable

- lamps
- small crates
- signs
- flowers
- minor barrels
- small decorative props
- flags
- minor vegetation

Goal:

> 풍성하게 보이지만 걷기는 편한 World.

## 18. Wayfinding

Portfolio 방문자는 게이머가 아닐 수 있다.

따라서 게임적 탐험은 허용하되
길찾기는 매우 단순하게 유지한다.

### Required

목적지마다 최소 두 가지 이상의 시각 단서를 가진다.

Examples:

- building silhouette
- sign
- path direction
- emblem
- forecourt
- landmark

색상만으로 구분하지 않는다.

하지만 실제 Portfolio 콘텐츠는 현대적인 글꼴과 레이아웃을 사용한다.

### World Label Example


장문의 설명은 World에 직접 노출하지 않는다.

---

## 21. Interaction Philosophy

Portfolio World는 게임이 아니라
**게임의 탐험 경험을 빌린 Portfolio Interface**다.

따라서 다음은 권장한다.

```text
Walking
Discovering
Entering a destination
Simple interaction
Short environmental information
```

다음은 기본적으로 피한다.

```text
Maze
Key hunting
Mandatory quest
Forced NPC dialogue
Long travel
Grinding
Combat
```

---

## 22. Player Character Direction

현재 Player size와 movement는 Sprint 1~2 기준을 유지한다.

Visual Style은 추후 확정한다.

방향:

```text
Small readable sprite
Professional / casual explorer feeling
Not fantasy hero
Not chibi mascot-heavy
```

현재 단계에서는 최종 character art를 만들지 않는다.

---

## 23. Pixel / Rendering Direction

현재 Art Direction은:

```text
16-bit inspired
```

이지 실제 16-bit 제한을 그대로 구현한다는 뜻은 아니다.

목표:

- Pixel-art inspired silhouette
- Retro tile-map readability
- Modern display readability
- 적당한 디테일

정확한 sprite / tile pixel scale은
Visual Prototype 단계에서 결정한다.

---

## 24. Reference Usage Policy

다른 게임은 참고 자료다.

사용 가능:

- layout principle
- density
- scale feeling
- color inspiration
- landmark usage
- RPG navigation conventions

사용 금지:

- exact map copying
- sprite copying
- building copying
- asset extraction
- copyrighted game art reuse

모든 최종 asset은 프로젝트 자체 제작 또는 적절한 라이선스를 가진 asset을 사용한다.

---

## 25. Avoid List

다음 방향으로 흐르지 않도록 한다.

```text
Specific game clone
Pirate theme overload
Heavy medieval fantasy
Dark harbor
Overly cute chibi world
Visual clutter
Maze navigation
Too many colliders
Retro UI reducing readability
World decoration overpowering portfolio content
```

## 26. Implementation Phases

### Visual Pass 1

목표:

**Harbor Square가 항구도시로 보이게 만들기**

Scope:

- plaza material
- waterfront hint
- dock
- water
- harbor landmark
- representative props
- destination building silhouette refinement

전체 최종 asset 제작은 하지 않는다.

### Visual Pass 2

목표:

**Zone별 identity 강화**

Scope:

- Guild Hall surroundings
- Academy surroundings
- Workshop surroundings
- Exhibition Hall surroundings
- signs
- forecourt design

### Visual Pass 3

목표:

**Environmental storytelling**

Scope:

- market
- crates
- barrels
- ropes
- plants
- lamps
- small cargo
- secondary props

### Final Art Pass

목표:

- asset consistency
- visual polish
- palette consistency
- animation
- final environment art

Final Art는 기능 구조가 충분히 검증된 이후 진행한다.
