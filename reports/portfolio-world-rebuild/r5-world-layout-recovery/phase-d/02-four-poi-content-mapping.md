## Alternative retained for review

Hall → Gallery and Archive → Teaching is visually literal for an exhibition building, but makes the Archive less distinct and weakens the direct learning/inquiry route. Workshop → Making and Hero Ship → Career remain unchanged in this alternative.

## Interaction contract (draft)

Each R5 POI uses its existing exterior approach/threshold, an 86-unit proposed interaction radius, E/Enter, and a visible pointer/touch prompt. It must never auto-navigate on proximity. Content pages retain browser Back today; a relative `world/` return link is proposed only for a later approved implementation pass.

One spatial POI can reveal several content sections or future subpages. POI count is an orientation decision—not a page-count constraint—and must not force another building.
