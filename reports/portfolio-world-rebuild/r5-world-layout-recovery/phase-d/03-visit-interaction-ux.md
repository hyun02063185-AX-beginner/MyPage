# R5 Phase D — Visit Interaction UX

All models begin with a real approach to the C.2 destination surface: named place prompt → deliberate E/Enter or click/tap activation. Proximity alone must not navigate. Mobile requires the visible prompt to include a large touch target and accessible label.

| Model | Visit and return | Benefit | Cost / open issue |
|---|---|---|---|
| A. Existing HTML page | Prompt opens current HTML; Browser Back returns to prior World URL | Reuses mature content; no duplicate content | Context switch; explicit World return link is not yet present |
| B. World overlay/panel | Prompt opens accessible summary panel; close restores exact place; optional link opens page | Strong spatial continuity | New R5 UI, accessibility, and content-curation work |
| C. Content scene | Prompt enters separately loaded space with explicit return seam | Most spatially expressive | Highest art/runtime cost; can become a barrier to portfolio content |

Recommendation: use A as the lowest-risk future implementation baseline, with an explicitly designed World return affordance. This is a proposal only; no R5 interaction is implemented.
