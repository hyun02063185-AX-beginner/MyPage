# R5 Phase D — Four-Destination Content Mapping

## Option A — Storytelling-oriented

| Space | Target | Why |
|---|---|---|
| Exhibition Hall | `teaching.html` | A public landmark naturally introduces the teaching program and its existing inquiry CTA. |
| Workshop | `making.html` | The page directly describes making, Human/AI roles, validation, and produced work. |
| Harbor Archive | `gallery.html` | The gallery is already a browsable concept/reference collection. |
| Hero Ship | `career.html` | A chronological professional journey is legible at a ship threshold without claiming ship exploration. |

## Option B — Semantic-oriented

Hall → `gallery.html`; Workshop → `making.html`; Harbor Archive → `teaching.html`; Hero Ship → `career.html`.

This makes Hall-as-gallery immediately literal, but removes the direct teaching/inquiry path from the main landmark and makes Archive less distinct as a reference space.

## Recommendation

Option A is recommended for review, not approved. It best supports an AI specialist instructor portfolio: learning offer first, method second, reference material third, career journey as the harbor symbol. A POI is an orientation unit rather than a one-page limit; future subtopics can be added without a fifth building.
