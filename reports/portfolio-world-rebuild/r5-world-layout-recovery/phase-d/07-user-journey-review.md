# R5 Phase D — User Journey Review

## Scenario 1 — Teaching inquiry

World entry → Exhibition Hall discovery → explicit visit prompt → teaching content → existing inquiry CTA. Option A shortens the route to the portfolio’s conversion purpose. A future explicit World return control is required if users should continue exploration.

## Scenario 2 — Method and results

World entry → Workshop → making method and public work links → Harbor Archive → supporting AI/AX concepts. The destinations are related but not duplicates, so users can continue with intent rather than travel for a page link.

## Scenario 3 — Professional confidence

World entry → Hero Ship boarding threshold → career narrative → Hall teaching offer. The Ship metaphor supports career chronology but does not claim a playable deck.

The map is a discovery layer, not the portfolio’s gatekeeper. Future implementations should offer clear orientation, short critical paths, mobile activation, and a return route before adding decorative travel distance.
