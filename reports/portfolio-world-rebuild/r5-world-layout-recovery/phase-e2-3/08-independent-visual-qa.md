# Independent visual QA

All evidence is rendered by the local Phaser Pilot in Edge headless, with the Workshop new-tab interaction additionally exercised in Chrome. The `qaPanel` capture query exists only to create reproducible visual evidence; ordinary play opens the panel only by E or visit button after arrival. The `route` captures use the real Pilot A* movement state.

No foreground is hidden or replaced; alpha assets depth-sort against player feet. The final board distinguishes actual covered areas from the unsupported shore stone wall rather than implying full painterly-mask coverage.
