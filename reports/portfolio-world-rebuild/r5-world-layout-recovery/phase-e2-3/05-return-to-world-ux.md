# Return to world UX

Opening content is a direct, `target=_blank` user action. The original Pilot tab is not navigated, remains at the same Workshop coordinates, and resumes when its panel is closed. Actual Chrome QA opened `making.html` in a new tab and then reselected the untouched Pilot tab, where Workshop was still active at `245,440`.

The panel closes before the new tab becomes active, so returning to the world does not leave movement frozen behind a dialog. This is a Pilot candidate, not a final portfolio navigation approval.
