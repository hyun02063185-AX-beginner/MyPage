# R5 Phase D.1 — Content Return UX Contract

Content mapping is approved; content entry remains pending. If an approved future implementation opens an existing HTML page, the UX contract should be:

1. Player reaches the named exterior interaction anchor.
2. A deliberate E/Enter/click/tap action opens the page; proximity never redirects.
3. Browser Back returns to the prior World URL as the current baseline.
4. A future explicit “Return to World” control should restore the last POI/approach identifier without an account or personal-data store.
5. Mobile must offer a visible touch activation and use platform Back safely.
6. Refresh or direct page entry should begin at a documented default World location rather than inventing a saved visit position.

No return control, state persistence, routing, or content-entry mechanism is implemented in D.1.
