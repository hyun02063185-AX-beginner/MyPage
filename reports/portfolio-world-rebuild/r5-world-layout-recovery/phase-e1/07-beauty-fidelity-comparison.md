# Beauty fidelity comparison

`16-beauty-master-vs-reconstruction.png` compares immutable Candidate B with the E.1 reconstruction under identical 1280×720 framing.

The original ship silhouette, gangway connection, dock footprint, Hall mass, and Workshop roof are retained by source-matched extraction; there is no second ship or newly invented building. Color/lighting stay close because foreground structures originate in Candidate B.

The trade-off is visible in estimated background regions: the generated terrace/water has slightly different brush density and local perspective. This is a material art-direction gap, so fidelity is CONDITIONAL for both regions rather than PASS.
