# Common world base contract

`11-common-clean-base.png` is a single 1280×720 base. Its starting image is immutable Candidate B. Workshop/Hall repair pixels come only from the committed E.1 Workshop generation source; Hero/Dock repair pixels come only from the committed E.1 Hero generation source. Each source is pasted only through its owned edit mask.

The Hall, Workshop, Archive approach, promenade, dock, gangway, and Hero Ship are subsequently reconstructed on this same base. There is no zone-specific full background, no new landmark, and no right-reserve modification.
