# Destination discoverability design

Candidate B remains untouched. Four compact, dark-navy, gold-accented DOM UI markers float at semantic world anchors. They are not new signs, collision, land, or scenery. Default state shows icon and bilingual name; hover/focus and selection reveal the content description and “click to move” guidance. Selected routes retain the existing yellow dotted route. Arrival is green-accented and retains the existing E-preview affordance.

The first-visit, closable Korean guide reads: “항구의 네 공간을 탐험해 보세요. 장소를 클릭하면 캐릭터가 이동합니다.” Bottom POI buttons remain as an equivalent control surface.
