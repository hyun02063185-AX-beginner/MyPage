# Independent visual QA

This is an independent R5 E2 Hybrid Pilot artifact, not Canonical R4 or a formal R5 Runtime. The default camera remains zoom 1.25. `pose`, `overview`, `qaFreeze`, and `rawSideQa` are capture-only query switches used to make reproducible visual comparisons; they do not alter default play.

Visual review finds the markers restrained relative to Candidate B: transparent navy panels, ivory text, a small gold icon, and no glow. The mobile evidence originally exposed a clipped Route Guide button; the final 700px media rule changes bottom controls to a two-column grid with a full-width Route Guide row.
