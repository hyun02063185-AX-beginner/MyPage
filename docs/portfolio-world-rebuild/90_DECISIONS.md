## Open — carried forward, not resolved through R2A

1. **The original "Concept Image #1" binary was not found.** A full search of the current working tree and `git log --all --diff-filter=A --name-only` across this repository found no concept-art image file. `00_VISUAL_BRIEF.md` §2 records the v1 art-direction document's written description as the canonical fallback. If the original image surfaces later (design tool export, external asset store, a contributor's local copy), attach it to `00_VISUAL_BRIEF.md` as a supplement — it does not retroactively invalidate decisions made from the written fallback.
2. **Exact numeric values are deliberately not locked**: camera elevation/projection angle (test matrix defined in `06_SCALE_CAMERA_CALIBRATION_PLAN.md`, not chosen), exact pixel coordinates for Candidate A's crescent, tile/logical-unit size, plaza stone-tile scale factor, water-ripple parameters, vessel water-contact geometry, exact color HEX values, exact light angle/value. Every number must be validated at actual gameplay render scale before being treated as final. This is a deliberate process change from v1, not an oversight — see `03_REBUILD_WORKFLOW.md` and `06_SCALE_CAMERA_CALIBRATION_PLAN.md`.
3. **`level-design` (`gamedev-skills/awesome-gamedev-agent-skills`) remains unadopted.** Its combat/pacing/gating vocabulary needs a stripped-down profile before it's useful for a no-combat walkable world. Revisit only if a future pass needs formal reachability-graph validation across more than four destinations (`02_SKILL_STACK.md`).
4. **No license audit was performed beyond the top-level repository license field** for any vendored source. Before reusing more than the currently-vendored file lists from any of the three sources, re-check licensing for the additional files.
5. **The project-owned runtime QA harness is not yet implemented as code.** `07_RUNTIME_QA_PLAN.md` names its check goals and suggested shape, but no script exists yet — this is deliberately deferred past R2A, which remains architecture-and-plan only (no runtime created).
6. **Whether/how `world-v2/` eventually relates to v1's `world/` and root `index.html`'s link** is explicitly not decided. R2B builds `portfolio-world-v2`/`world-v2` alongside v1 with zero interference; a future merge/replacement decision is out of scope for both R1 and R2A.
