- Candidate A+ is implemented as an isolated Graphics-only Phaser 4.2.1 blockout in `portfolio-world-v2/`, built to committed `world-v2/`; `portfolio-world/**`, `world/**`, v1 assets, and the root site link remain untouched. `BootScene` starts the single `WorldScene` as proposed in `04_ARCHITECTURE_V2.md`.

### R2D blockout repair decisions (2026-09-26)

- **Branch origins are spine vertices, defined once.** `SPINE`, `GUILD_BRANCH`, `ACADEMY_BRANCH` and `SQUARE` are shared constants in `WorldScene.ts`; both drawing and walkability read them. R2B's junction cluster came from hard-coded branch origins (Guild (720,770), Academy (1080,630) inside the Square's x-range), so the repair moved the origins, not the markers. New order along the spine: working dock -> Guild stub (560,835) -> Harbor Square (centre 695,585, a widening on the spine) -> Academy branch (1085,656) -> Exhibition Hall -> Hero Quay. Candidate A+ is unchanged; only its numeric implementation moved.
- **Guild/Academy origins must not be near-equidistant from the Square.** An intermediate attempt (323 vs 328 px from the Square centre) recreated the mirror-through-the-square pattern of `05_HARBOR_BLOCKOUT_SPEC.md` §6 and was rejected. Final: 284 vs 396 px.
- **Door placeholder is fixed at 38 x 68 px (~1.26x the 54 px player)** on the hall ground line and no longer scales with the projection. The `scale` QA state puts the player beside the door on the same ground line. 1.2–1.5x remains a judging range, not a production dimension.
- **Projection variants exchange facade/hull-side for top-plane/deck** (hall facade 252/186/130 with roof plane growing; hero hull+topsides shrinking as a deck plane grows; quay side face 46/14/0) instead of nudging heights. Hall total height is held roughly constant. Camera remains an identical 2D orthographic camera. No variant is selected; the comparison is re-run by the independent recheck.
- **Walkable corridors derive from the drawn routes.** R2B's basin exclusion made the drawn Square -> Exhibition -> Hero Quay route unwalkable where it overlaps the basin edge; fixed as part of making the route constants the single source of truth (Level-D verified only).
- **QA harness takes `--set <phase>` (default `r2d`).** `r2b` is historical evidence and is refused unless `--allow-overwrite-historical` is passed. One harness, no copy.
- **R2D self-grades nothing visual.** Evidence is in `reports/portfolio-world-rebuild/evidence/r2d/`; the three R2C Majors are addressed in code but are judged by the independent recheck. Final Gate: `READY_FOR_R2D_INDEPENDENT_RECHECK`. Report: `reports/portfolio-world-rebuild/r2d-blockout-repair.md`.
